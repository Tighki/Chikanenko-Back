# API заселения в общежитие

Сервер дипломной системы: проверка заявок, импорт выгрузки приёмной комиссии и автозаселение. Фронт живёт отдельно: https://github.com/Tighki/Chikanenko

## Порты

| Что | Порт | Проброс на роутере |
| --- | --- | --- |
| Этот API | 4000 TCP | Да, на IP машины с Node |
| Фронт | 5173 TCP | Да, на IP машины с фронтом |
| PostgreSQL | 5432 | Нет |

`5432` остаётся только на `127.0.0.1`. В таблицу проброса его добавлять не нужно.

## Env

Скопируйте пример и подставьте адрес, которым браузер открывает сайт. Если заходите по внешнему IP `203.0.113.10`, в бэке и во фронте должен быть он, а не адрес из локальной сети.

```bash
cp .env.example .env
```

```env
DATABASE_URL=postgresql://hostel:hostel@127.0.0.1:5432/hostel
JWT_SECRET=change-me-before-defense
HOST=0.0.0.0
PORT=4000
CORS_ORIGIN=http://203.0.113.10:5173
```

`CORS_ORIGIN` — адрес страницы фронта, включая порт. Несколько адресов пишутся через запятую. Пустое значение или `*` разрешает любой адрес.

На фронте в этот момент стоит `VITE_API_URL=http://203.0.113.10:4000`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run db:local
```

Окно с базой не закрывать. Во втором окне:

```bash
cp .env.example .env
npm run db:setup
npm run build
npm start
```

Проверка: `http://127.0.0.1:4000/api/health` отвечает `{ "ok": true }`.

`db:setup` применяет миграции и заново заполняет демо-данные. Повторный запуск очищает базу.

Docker, если он есть на сервере: `docker compose up -d` поднимает PostgreSQL на `127.0.0.1:5432`. Команда `db:local` тогда не нужна. Наружу контейнер не публикуйте.
